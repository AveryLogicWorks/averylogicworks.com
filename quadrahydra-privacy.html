QuadraHydra Application Privacy

QuadraHydra 1.0.3 — Application Privacy Notice Effective date: September 3, 2026 Responsible seller: Chad Avery Harris, trading as Avery Logic Works Privacy contact: Averylogicworks@gmail.com

Scope

This notice describes the QuadraHydra desktop application. It does not substitute for the disclosures required for the Avery Logic Works website, checkout, email delivery, analytics, or support systems. Review those disclosures separately when using those services.

Information handled on your computer

QuadraHydra reads information about running processes and system resource use so it can display the process list, CPU and memory statistics, priorities, and available controls. It may read executable paths when you use related controls. That processing occurs locally.

The application stores settings, trial start and expiry records, activation state, agreement acceptance records, and diagnostic/activity logs under %LOCALAPPDATA%\AveryLogicWorks\QuadraHydra. Logs can contain timestamps, process names and identifiers, changes you requested, errors, and local file paths. Existing settings or license records beside the app may be copied into the per-user data folder during migration. Original migration files are retained.

The app does not automatically upload these local files or the process list. It does not contain an advertising or behavioral-analytics reporting feature in this build. License and trial validation run locally; no licensing account or payment card is required to start the desktop trial.

Update requests

The application automatically checks a release manifest hosted using Supabase and offers a manual update check. The request obtains public version information. It does not include your activation key, process list, or local file contents as application payload.

As with an ordinary HTTPS request, the service handling it receives network information such as your IP address, request time, and HTTP request metadata. The hosting provider may retain request logs according to its service practices. Following an update or purchase link opens a website whose own privacy notice applies.

The current build has no in-app switch to disable the automatic update check. Blocking its network access prevents update checks; local process controls and offline license validation do not depend on successful update requests. This is a description of the current implementation, not a claim that the hosting provider retains no data.

Support and purchases

If you choose to send a diagnostic log to support, inspect it first and remove unrelated confidential information. No log is sent automatically. Information you send, such as your email address, order reference, and support message, must be handled under the separate support/website privacy disclosure. The desktop application does not process a payment itself.

Retention and choices

Local settings, activation records, trial records, and saved log files remain until removed from your computer; the inspected build does not impose an automatic log-deletion schedule. You control access through your Windows account and filesystem permissions. Removing an extracted app folder does not automatically remove its separate application-data folder or migration copies.

You may inspect or remove local files after closing the application. Removing settings or activation records can reset settings or require reactivation. Privacy choices do not grant permission to bypass the trial or use an unpaid license.

For information held by the Seller through purchases or support, contact Averylogicworks@gmail.com. Applicable rights, verification requirements, retention periods, and legally required recordkeeping must be described in the separate service privacy notice. No transmission or local storage arrangement is guaranteed completely secure.

Agreement records and website checkout

The desktop application saves the accepted terms version, document hashes, and acceptance time locally. These records are not uploaded automatically. The product page stores the accepted terms version and time in this browser when storage is available; the acceptance record is included in the PayPal purchase fields when you submit checkout. PayPal processes payment under its own privacy policy. Website and support processing is described at averylogicworks.com/privacy.html.
