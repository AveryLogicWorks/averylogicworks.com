What it does

  • Reads selected or copied text aloud from Windows applications
  • Uses SAPI voices already installed in Windows
  • Runs from a compact system-tray interface
  • Keeps speech processing local and available offline after setup

How to use it

  1. Select or copy the words you want to hear.
  2. Press Ctrl+Shift+Space.
  3. Speakeasy reads the selected or clipboard text aloud.
